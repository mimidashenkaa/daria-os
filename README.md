# DARIA/OS — Graphic Design Portfolio

Static HTML/CSS/JS portfolio built to deploy for free on GitHub Pages or Netlify. No build step required.

## Preview locally
From this folder run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Deploy free with GitHub Pages
1. Create a new public GitHub repository.
2. Upload all files from this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

## Main files
- `index.html` — Home / selected work
- `work/*/index.html` — case studies
- `about/`, `experience/`, `archive/`, `contact/` — supporting pages
- `assets/css/styles.css` — visual system
- `assets/js/main.js` — DARIA/OS interactions, reveal, archive filters
- `assets/images/` — selected portfolio images
